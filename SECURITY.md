# Security policy

## Scope

GmapsXploit is built for authorized testing. Run it only against keys and
accounts you own or have explicit written permission to test. Reports about
its behaviour on unauthorized targets are out of scope.

## Supported versions

Fixes land on `main`. There are no long lived release branches.

## Reporting a vulnerability

Open a private security advisory on GitHub or contact the maintainer. Do not
open a public issue for something that could be used before it is fixed.

Include:

- a short description and the impact
- the affected commit
- reproduction steps or a proof of concept
- any suggested fix
